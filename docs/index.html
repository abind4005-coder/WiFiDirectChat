Core Capabilities

Everything. Offline.

DMS packs enterprise-grade features into a completely offline, peer-to-peer Android app.

📡
WiFi Direct P2P Mesh
Connects phones directly using WiFi Direct (IEEE 802.11) — no router, no hotspot, no internet required. Works in disaster zones, remote areas, and offline events.
🔒
AES-256 Encryption
Every message is encrypted with AES-256-CBC before transmission. Your conversations stay private even if intercepted on the mesh network.
📞
Real-Time Voice Calls
Full-duplex voice calling over TCP (port 9050) using Android AudioRecord + AudioTrack. Crystal-clear calls with mute, speaker toggle, and live call timer.
⛓️
Blockchain Message Integrity
SHA-256 blockchain ledger records all messages with tamper-proof hashes. Verify every conversation hasn't been altered — ideal for secure, auditable comms.
📁
Offline File Transfer
Send files of any type directly over the mesh at up to 8 MB/s. Images, PDFs, documents — all transferred securely without cloud storage.
📻
LoRa Long-Range Mode
Arduino + LoRa module integration extends mesh range to kilometers. DMS bridges WiFi Direct with LoRa for true last-mile offline communication.
How It Works

Connect in 3 Steps

No accounts. No servers. No internet. Just tap and connect.

01
Tap the Radar Scanner
Open DMS and press the circular radar button. The app scans for nearby Android devices with DMS installed using WiFi Direct discovery — no setup needed.
02
Select & Connect
Nearby peers appear on your screen. Tap a device to initiate a secure WiFi Direct connection. AES-256 encryption is automatically negotiated during handshake.
03
Chat, Call & Share
Send encrypted messages, make voice calls, transfer files, or record voice notes — all in real-time, completely offline. Every message is logged on the blockchain ledger.
